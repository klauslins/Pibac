# 02_PLANNING — Planejamento e calendário

> **O que vai ao ar, quando e por quê.** A ponte entre a estratégia (01) e o
> texto que será escrito (03).

## O que vai aqui

| Subpasta | O que guarda |
|---|---|
| `calendario/` | Calendário editorial, uma pasta por trimestre: `2026-Q3/` |
| `briefings/` | Briefing de cada campanha, a partir do modelo |
| `pautas/` | Ideias e temas em avaliação, antes de virarem campanha |

O [`briefings/_modelo-briefing.md`](briefings/_modelo-briefing.md) é o ponto de
partida. Quanto mais completo o briefing, melhor a entrega — vale para o time e
vale em dobro para IA.

## O que NÃO vai aqui

| Isso | Vai em |
|---|---|
| Posicionamento, persona, tom de voz | `01_STRATEGY/` |
| A legenda escrita | `03_CONTENT/copy/` |
| A arte da peça | `04_PRODUCTION/` |

## Como nomear

Data sempre do maior para o menor — assim a ordem alfabética já é a cronológica.

```
calendario/2026-Q3/calendario-2026-09.pdf
briefings/briefing-trafego-pago-set-2026.md
pautas/pauta-data-comemorativa-2026-09-22.md
```

```
✅ calendario-2026-09.pdf     ordena certo
❌ calendario-set-2026.pdf    "abr" vem antes de "set" no alfabeto
```
